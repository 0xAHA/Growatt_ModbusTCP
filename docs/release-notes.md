Home Assistant also shows the notes for a pending update in **Settings → Devices & Services → HACS** before you install it.

---

## Before updating

Most releases need nothing from you. When one does — an entity renamed, a sensor removed, a setting that has to be re-entered — it is called out at the top of that release's notes rather than buried in the list.

If an update causes a problem, the [previous releases](https://github.com/0xAHA/Growatt_ModbusTCP/releases) page lets you install any earlier version, and [raising an issue](troubleshooting/raising-an-issue.md) with the version you came from is the most useful thing you can report.
